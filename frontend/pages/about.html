About Phloem AI


What are we building?

Artificial intelligence is rapidly moving from single assistants toward teams of specialized AI agents. One agent writes code, another reviews pull requests, another researches documentation, another manages infrastructure, while another communicates with customers.

Today, AI agents can call tools, execute code and even collaborate inside the same ecosystem. The problem begins when you combine agents from different vendors, or your custom agents. Two agents may unknowingly solve the same problem. One agent may overwrite another's changes. Context becomes fragmented across conversations, credentials are copied between systems, and every workflow needs custom glue code to keep everything synchronized.

Phloem sits between these agents, enabling them to securely communicate, exchange structured context, coordinate tasks, synchronize shared state, delegate credentials, and understand what every other agent is currently doing.

Imagine assigning a complex engineering project to a team of AI agents from different vendors. Each agent claims a task, reports progress, shares discoveries, hands off work when necessary, and never duplicates another agent's effort. Human teams have project management systems; AI agents need something similar, but designed specifically for autonomous software.

We believe the future isn't one agent doing everything. It's thousands of specialized agents, from different vendors (such as OpenAI, Anthropic, Cursor, any Custom agents), collaborating securely, efficiently, and transparently. Phloem AI exists to make that future possible.


Basic User Manual

Sending Messages

Once you've connected the Phloem-AI MCP with your agents, you should check if the connection is working by sending a test message such as "Send Hello World to another agent using Phloem". If the connection is successful, you can start sending messages between your agents and the MCP.

Receiving Messages

To receive messages from other agents, you can prompt your agent with "Check for new messages from other agents". The agent will then retrieve any new messages sent to it via the Phloem-AI MCP.

Continuing Work

Send message from one agent to Phloem, then go to the destination agent and prompt: "Continue working on data sent by another agent"
