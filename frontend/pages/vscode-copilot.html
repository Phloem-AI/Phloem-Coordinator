Connecting Remote MCP in VS Code Copilot

VS Code can expose remote MCP tools to GitHub Copilot Chat. This guide configures a server in the workspace .vscode/mcp.json file using Streamable HTTP.

1. Gather your server details

Collect the MCP endpoint URL, such as https://example.com/mcp, and the authentication method required by the server. The example below uses a bearer token.

2. Create the MCP configuration

In your workspace, create or open .vscode/mcp.json. For a user-wide server, run MCP: Open User Configuration from the Command Palette instead.

3. Add the remote server

Use the VS Code configuration schema with a servers object:

{
  "servers": {
    "my-server": {
      "type": "http",
      "url": "https://example.com/mcp",
      "headers": {
        "Authorization": "Bearer ${input:myMcpToken}"
      }
    }
  },
  "inputs": [
    {
      "type": "promptString",
      "id": "myMcpToken",
      "description": "MCP bearer token",
      "password": true
    }
  ]
}

Input variables keep the token out of source control. VS Code also supports environment variables and other configuration reference forms.

4. Start the server and review trust

Save mcp.json. Use the inline controls in the file, the MCP view in Extensions, or MCP: List Servers from the Command Palette to start it. Review the configuration and confirm that you trust the server.

5. Use and troubleshoot the tools

Open Chat and ask Copilot to use the server:

Use the my-server tools to inspect the current project status.

Use Configure Tools to select available tools. If a server fails, select its error indicator or use MCP: List Servers → Show Output to view logs.

Tip: Remote MCP servers are configured with type: "http" in VS Code. Local command-based servers use type: "stdio". Only add servers you trust, and keep credentials in input variables or environment configuration.
