Connecting Remote MCP in Linear Agents

Linear Agents can connect to any remote MCP server to bring external tools, data sources, and workflows directly into Linear. This guide covers the setup using Linear's Agent API and OAuth2 authentication.

1. Create a Linear application

Sign in to Linear and go to Settings → API → Applications. Create a new application and enable Agent session events webhooks. Note your client ID and client secret.

2. Configure OAuth scopes

In your application's OAuth URL, add the actor=app parameter to switch to app installation mode. Request the scopes your MCP server needs. Workspace admins must approve the installation.

3. Register your MCP server endpoint

In your agent's configuration, register the remote MCP server endpoint. Linear Agents communicate with MCP servers over HTTP (Streamable HTTP) or SSE. Provide:

  • Endpoint URL: https://example.com/mcp
  • Transport: HTTP or Streamable HTTP
  • Authentication: Bearer token or OAuth 2.0

4. Handle agent session webhooks

Your agent receives AgentSessionEvent webhooks when mentioned or delegated. Respond within 10 seconds with a thought activity, then use the MCP tools to fulfill the request. Use the promptContext field to construct your agent's prompt from issue details and guidance.

5. Test the integration

Mention your agent in a Linear issue or assign an issue to it. The agent should respond using tools from your MCP server. Check the Agent Session UI in Linear to monitor progress.

Tip: Linear's Agent Session lifecycle is tracked automatically. Emit action activities for tool calls, response for final answers, and error for failures. Use externalUrls to link back to your agent's dashboard.
