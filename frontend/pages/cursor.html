Connecting Remote MCP in Cursor

Cursor supports remote MCP servers over Streamable HTTP and SSE. This guide uses Cursor's mcp.json configuration and a bearer token example.

1. Gather your server details

Get the remote MCP endpoint from your provider, such as https://example.com/mcp. Confirm whether it uses Streamable HTTP or SSE and whether it requires a bearer token or OAuth.

2. Open Cursor's MCP configuration

For a project-only connection, create or open .cursor/mcp.json in the project root. For a global connection, use ~/.cursor/mcp.json. You can also manage servers from Cursor's Customize page.

3. Add the remote server

Add a server entry. Cursor uses url for both remote HTTP and SSE connections:

{
  "mcpServers": {
    "my-server": {
      "url": "https://example.com/mcp",
      "headers": {
        "Authorization": "Bearer ${env:MY_MCP_TOKEN}"
      }
    }
  }
}

Set MY_MCP_TOKEN in your environment before starting Cursor. Do not commit a real token to mcp.json.

4. Trust and enable the server

Restart or reload Cursor so it discovers the server. Review the server configuration and approve the trust prompt. Use the Customize page to enable or disable the server and limit available tools.

5. Test the connection

Open Chat and ask Cursor to use the server by name, for example:

Use the my-server tools to inspect the current project status.

Approve the tool call when prompted. For connection failures, open the Output panel and select MCP Logs.

Tip: Cursor supports OAuth for remote servers. If your provider uses OAuth, configure the server URL without a static bearer header and complete authentication through Cursor. Register the callback URL required by the Cursor surface you use.
