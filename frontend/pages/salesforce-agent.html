Connecting Remote MCP in Salesforce Agent

Salesforce Agentforce can connect to any remote MCP server to bring external tools, data sources, and workflows directly into your Salesforce environment. This guide covers the setup using Salesforce's external tools integration.

1. Open your Salesforce Agent settings

In Salesforce, open Agent Builder or Agentforce in your sandbox or production org. Make sure your user has the Manage External Tools or Author Apex permission.

2. Create a new MCP connection

Go to Setup → External Tools or Agent Builder → Tools. Create a new external service and choose the option for a remote MCP endpoint. Select HTTP or Streamable HTTP as the transport.

3. Enter the server details

Provide the MCP server configuration:

  • Endpoint URL: https://example.com/mcp
  • Authentication: Bearer token or API key
  • Optional headers: any tenant or workspace identifiers required by your server

4. Save and attach the connection to your agent

Save the configuration and assign the MCP connection to the specific agent or action that should use it. This is done in the agent's tool or capability settings.

5. Test inside Salesforce

Start a conversation with the agent and ask it to invoke the newly connected MCP tools. If the connection is correct, the agent will be able to call the remote MCP server and return the result.

Tip: If the agent cannot discover the tools, confirm that the endpoint is reachable from your Salesforce environment and that the auth token has the correct permissions. Salesforce may require you to add the endpoint to a Remote Site Setting first.
